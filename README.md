📊 ECOMM DATA Project

A data analytics project containing multiple Excel dashboards and reports including E-commerce analysis, HR Dashboard, and Student Information System.
This repository showcases data cleaning, analysis, and dashboard creation using Excel.

📁 Repository Contents

ECOMM DATA (AutoRecovered).xlsx
E-commerce dataset containing sales, customer, and order information used for analysis.

HR Dashboard (1).xlsx
Interactive HR dashboard analyzing employee data such as attrition, department performance, and demographics.

Student Information System (1).xlsx
Student data management and analysis including performance tracking and records.

EFM I.docx & EFM II.docx
Documentation and project reports.
